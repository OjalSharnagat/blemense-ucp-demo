# PulseCart Demo (Frontend Only)

A Vite + React demo e-commerce platform with:

- Storefront with product listing, featured cards, category/search filters
- Cart flow with quantity updates and checkout simulation
- Admin product management for add/edit, price updates, stock management, variants (size/color), and image URL/file upload
- Kick X-style enterprise admin dashboard UI with sidebar, KPI cards, analytics widgets, table-first product operations, and slide-over editor
- Catalog controls for feature toggling and deletion, plus order status updates
- LocalStorage persistence for products, cart, and orders

## Run locally

```bash
npm install
npm run dev
```

## Demo notes

- No backend or API integrations are used.
- All data is client-side and persisted in browser localStorage.
